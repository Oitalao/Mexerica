## O que há de novo

- **Dividir PDF: ao lado do original, numa pasta ou num ZIP:** a janela de Dividir ganhou "Onde salvar". O padrão põe as partes na mesma pasta do PDF ("nome - parte 1 de 3 (p. 1-2)"); "Pasta" junta as partes numa pasta nova "nome (partes)"; "ZIP" entrega um ZIP só com todas as partes. "Desfazer" no aviso apaga todas as partes.
- **A linha de comando faz tudo o que a roda faz:** `mexerica acao` (Renomear, Copiar, Mover, Caminho, Terminal, Compartilhar, Flutuar), `mexerica ajuda "<nome>" <arquivos>` mostra os ajustes de cada ferramenta com os valores padrão, e as ferramentas usam os mesmos padrões e conferências da janela de ajuste. `mexerica vigiar` também comprime (`--acao comprimir` ou `ambos`). Metadados sem ajustes mostra os metadados; Ler QR mostra o texto lido.
- **Verificar integridade do programa (ícone perto do relógio):** confere se as ferramentas (FFmpeg, Ghostscript, qpdf, ExifTool, LibreOffice), o menu do botão direito e a pasta de dados estão bem. É o mesmo que `mexerica doctor`.
- **IAs de linha de comando já sabem usar o Mexerica:** se o Claude Code ou o Codex estiverem instalados, o Mexerica deixa para eles um guia completo de uso do comando `mexerica` (todos os formatos, ferramentas e ajustes desta versão), para que usem o Mexerica em vez de instalar outros programas. O guia é reescrito sozinho a cada atualização; desinstalar o Mexerica o apaga.

## Mudanças

- **O comando `mexerica` vem sempre:** o instalador não pergunta mais; o comando entra no Prompt de Comando e no PowerShell sozinho.
